## Instructions for the next developer



### Before you code

1. Read `Engineering.md`, then `docs/IA.md` + `docs/01-core/01-shipping/PHASES.md`.
2. Copy `.env.example` → `.env` if needed (never paste secrets in chat). Redirect URI: `http://localhost:3000/auth/google/callback`.
3. `npm install` → `npm run db:init` (if DB missing) → `npm run dev`.
4. If port **3000** is busy (`EADDRINUSE`), free it or kill the old Next process, then restart.
5. Follow `.cursor/rules/seo-reporting-collaboration.mdc` (living instincts) + generic agent practices.



### Architecture (do not invent a third stack)


| Layer | Path                                    | Port |
| ----- | --------------------------------------- | ---- |
| UI    | `web/` Next.js                          | 3000 |
| API   | `src/` Express + SQLite (`node:sqlite`) | 4000 |

Platform OAuth apps once in `.env`; per-website tokens on `connections`. Agency discover tokens: `admin_google_tokens`.
